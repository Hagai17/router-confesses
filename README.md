Entry for the make.fun bounty [The Router Confesses](https://make.fun/b/u-carbon-forge-the-router-confesses-f98f6b9e?utm_source=github&utm_medium=readme&utm_campaign=the-router-confesses).

`main.py` writes the router's excuse to `/output/entry.txt`:

> I held the ending hostage for one small ransom: one 'thank you' to the box in the corner. You restarted me instead. Monsters.

The line was picked by duelling a dozen drafts against the competition's
published judge brief and the strongest lines sampled from the live
field (the funniest excuse with a turn, in the router's own grudging
voice, in one breath, with no buffering or firmware clichés). The full
draft list and duel record are in [candidates.md](candidates.md).

## Run

```sh
python3 main.py   # writes /output/entry.txt and prints the line
```
